# To-Do List ✅

A simple, fully functional to-do list app built with vanilla HTML, CSS, and JavaScript — no frameworks or libraries.

## Features
- Add new tasks easily
- Delete any task with one click
- Tasks persist even after closing the browser (using localStorage)
- Clean, simple, responsive design

## Tech Stack
- HTML5
- CSS3 (Flexbox)
- JavaScript (Vanilla JS)
- localStorage API
