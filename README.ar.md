# To-Do List ✅

تطبيق بسيط لإدارة المهام اليومية، شغال بالكامل بـ HTML, CSS, و JavaScript من غير أي مكتبات خارجية.

## المميزات
- إضافة مهام جديدة بسهولة
- حذف أي مهمة بضغطة واحدة
- المهام بتفضل محفوظة حتى لو قفلت المتصفح (باستخدام localStorage)
- تصميم بسيط ونظيف، متجاوب مع الشاشات المختلفة

## التقنيات المستخدمة
- HTML5
- CSS3 (Flexbox)
- JavaScript (Vanilla JS)
- localStorage API
